# Islam Ayman Studio

برنامج DJ ISLAM AYMAN لظبط الأغاني: فرانكو للأسامي، كفر، بلاي ليستات، رفع الجودة، شيل بصمة الصوت، ومعرفة أسامي التراكات في الميكس.

## التنزيل
من صفحة **Releases** على يمين الصفحة، نزّل:
- **Windows:** `Islam-Ayman-Studio-Setup-1.3.0.exe`

## البناء من الكود
```bash
npm install --ignore-scripts
npx electron-builder --win
```

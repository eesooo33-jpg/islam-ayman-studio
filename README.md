# Islam Ayman Studio

برنامج DJ ISLAM AYMAN لظبط الأغاني: فرانكو للأسامي، كفر، بلاي ليستات، رفع الجودة، شيل بصمة الصوت، ومعرفة أسامي التراكات في الميكس.

## تسطيب البرنامج على الويندوز

1. فوق في الصفحة دي، دوس الزرار الأخضر **Code**، وبعدين **Download ZIP**.
2. افتح فولدر **Downloads**، ودوس كليك يمين على الملف اللي نزل واختار **Extract All** ثم **Extract**.
3. ادخل فولدر **Windows-Setup**، ودوس مرتين على **INSTALL.bat**.
4. البرنامج هيتجمّع ويبدأ التسطيب. لو ظهرت شاشة زرقا "Windows protected your PC"، دوس **More info** وبعدين **Run anyway**.
5. كمّل التسطيب، وهتلاقي أيقونة **Islam Ayman Studio** على سطح المكتب.

(البرنامج متقسّم لجزئين لأن GitHub مش بيقبل ملف أكبر من 100 ميجا، و INSTALL.bat بيجمّعهم.)

## الكود
باقي الفولدرات دي كود البرنامج. للبناء من الكود:
```bash
npm install --ignore-scripts
npx electron-builder --win
```
